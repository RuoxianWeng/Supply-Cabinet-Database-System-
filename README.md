# Supply Cabinet Database System

Design a database system with a DBMS in MySQL Workbench for a company to maintain school supplies inventory and shipment information for elementary schools around the United States. 
Implemented a frontend web application using HTML, CSS, and PHP to provide a dynamic communication platform for users to interact with the database.

## Database Section:  
Set up a MySQL connection for DBMS in MySQLWorkbench.  
Create a Schema named School Supplies Co. 
Open this file ‘table creation.sql’ and compile to create all the tables.  
Open the file ‘data.sql’ and compile to add data to the tables
